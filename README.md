# HATWEAVE

**Geometry encryption — an open research question: can aperiodic geometry one day underpin quantum-resistant encryption? Experimental and theoretical only — not a working cryptosystem.**

HATWEAVE explores encryption built from *aperiodic geometry*: keystreams
generated by **cut-and-project** schemes — higher-dimensional lattices
projected through an irrational window — producing **Sturmian sequences**
that are fully deterministic yet never repeat. The two-dimensional
inspiration is the **hat tile** (Smith, Myers, Kaplan & Goodman-Strauss,
2023): the first single tile that covers the plane only aperiodically.

> ⚠️ **Experimental and theoretical only — NOT production cryptography.**
> See [DISCLAIMER.md](DISCLAIMER.md). For real post-quantum security today,
> use the NIST-standardized algorithms (ML-KEM, ML-DSA, SLH-DSA).

## Core idea in one paragraph

Shor's quantum algorithm is a period-finding machine. Aperiodic
keystreams have **no period to find**. HATWEAVE proposes that the secret
key be a set of geometric parameters (slope, phase, window — and in 2D, a
path through a hat-tile patch), that encryption regenerate the aperiodic
stream from that geometry, and that tampering be detected as *geometry
disruption*: a broken tiling announces itself. The thesis argues the
potential — and states the unsolved problems just as plainly.
